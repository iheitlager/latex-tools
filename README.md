A collection of Python tools for processing, validating, and comparing LaTeX documents. These tools help with common LaTeX workflows including file consolidation, bibliography management, DOI validation, and document comparison.

Python tools for LaTeX workflows:

- **LaTeX Processor**: Consolidate, validate, and export LaTeX documents. ([docs/latex_processor.md](docs/latex_processor.md))
- **DOI Validator**: Validate DOIs in BibTeX files. ([docs/doi_validator.md](docs/doi_validator.md))
- **LaTeX Diff Parser**: Compare two LaTeX files and generate a color-coded diff. ([docs/latex_diff_parser.md](docs/latex_diff_parser.md))
- **Make PDF**: Compile LaTeX to PDF with bibliography and cleanup. ([docs/make_pdf.md](docs/make_pdf.md))

See each tool's documentation page in the `docs/` folder for details and usage examples.
